# 中文数据分析 Agent 自查记录

2026-11-01 使用 DeepSeek Flash，在临时 JSON 存储和一份手写 6 行 CSV 上运行中文数据分析自查。样例、参考 SQL 和比较规则保存在 [eval_chinese_agent_smoke.py](../../scripts/eval_chinese_agent_smoke.py)。这是一组很小的合成开发样例，不是独立、人工标注的业务测试集，也不能代表通用准确率。

一次完整运行在调整结果选择提示词**之前**，10 道题按主要 SQL 的完整结果行及列数严格比较，有 **9/10** 匹配，详情见[运行明细](chinese_agent_smoke_flash_20261101.json)。这十题涉及求和、过滤、分组、去重、时间范围、Top 1 和空结果，只测试 SQL 结果，不评估自然语言正确性、多轮、画图、安全性或生产泛化；10 题仅一次运行。

## 发现的问题与复测

“去重后有多少个不同客户，只返回一个数”这一题：参考答案为 `4`。Agent 的 q1 已返回单列 `4`，q2 又查询了总行数、非空行数、去重数，模型选了 q2 作为主要结果，因此最终结果为三列，未满足单列要求。自然语言回答中的数字为 `4`；这不改变主要 SQL 严格判失败的结果。

据此补充了结果选择提示：存在直接满足用户所需字段和粒度的结果时，优先选择该结果而不是附带辅助字段的查询。调整提示后，仅对该**参与调试的题目**额外运行一次，返回单列 `4` 并选择 q1；[单题复测明细](chinese_customer_selection_retest_flash_20261101.json)。模型输出存在波动，这个 1/1 不能证明总体提升或保证以后总能选对，也不能与 9/10 组成新的 10/10 成绩。应在新的、未参与调参的题集上验证。

为避免 Top 1 题的并列顺序不确定，完整运行之前曾中断一次开发试跑并调整该题条件。中断前 5 题记录保存在 [部分开发记录](chinese_agent_smoke_partial_development_20261101.json)，不计入上述完整运行统计。每次运行均使用 Flash，不使用 Pro。完整运行累计模型用量为 68,909 tokens，中位耗时约 4.78 秒；实际费用以服务商账单为准。
